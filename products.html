TOOLS

ツール

VRChatやUnityで使うツールと、Windowsアプリ、Chrome拡張の一覧です。

ToolsWorldsArchive
Windows

HarmoFlow →

3DモデルとUV上でペイントし、レイヤーやマスクでテクスチャとマテリアルを編集するソフトです。
Unity

MameFont Baker →

使う文字を収集し、必要な文字だけを含むTextMeshProフォントアセットを作成・適用するツールです。
Unity

SanText →

アバターの改変手順を記録し、再適用や巻き戻しができるエディタ拡張です。
Unity

Pivocker →

一時的なピボットを置き、メッシュを変更せずにオブジェクトの回転や拡縮を行うツールです。
VRChat · Udon

B-Pen →

QvPenで描いた線の座標・色・太さを記録し、描画を再生する拡張スクリプトです。
Windows

VRC-Memory →

VRChatのログと写真を関連付け、活動履歴をタイムラインや統計で振り返るアプリです。
Unity

ElevaN →

パターンやノイズを重ね合わせ、プレビューを確認しながら質感テクスチャを作るツールです。
Chrome

Boopa - BOOTH Price Tracker for VRChat →

BOOTHのVRChat関連商品の価格履歴を、商品ページ上にグラフで表示する拡張機能です。
Unity

EmoSpark →

IK・FKや指の制御、ミラー編集を使い、Humanoidのポーズとアニメーションを作るツールです。
Windows

PiPツール（Window） →

ウィンドウ全体や指定した領域を、最前面の小さなウィンドウに表示するツールです。
Unity

SDF TextGen 3D →

TrueType・OpenTypeフォントから、厚みを調整できる3D文字メッシュを生成するツールです。
Unity

BlendShapeCollector →

メッシュのブレンドシェイプ設定値をリストに保存し、対象のメッシュへ適用するツールです。
Unity

Phys Bone.jp →

公式スクリプトを変更せず、日本語のUIからPhys Boneの設定を編集するツールです。
Unity

Image Viewer →

Scene上に参考画像を表示し、有料版では動画や連番画像も再生できるツールです。
Unity

VCC Template Builder →

ツールやアセットを含むVCC・ALCOM向けのプロジェクトテンプレートを作るツールです。
Unity

PoseMenuBuilder →

Modular Avatarと連携し、ポーズやモーションをExpression Menuへ一括登録するツールです。
Unity

Scene Assets Compression →

Scene上で対象を確認しながら、テクスチャサイズをまとめて調整・圧縮するツールです。
Unity

ItemToggleBuilder →

アバターのメッシュを選び、Modular AvatarでON・OFF切り替えメニューを生成するツールです。
Windows

VRC YouFix →

YouTubeやニコニコ動画のURLを、VRChatで再生するための形式へ変換するツールです。
Unity

AvatarBinder →

改変したアバターをプレハブごとにUnityPackageとして保存し、一覧で管理するツールです。
Unity

BOOTH Package Manager →

UnityPackageを一覧で管理し、複数のプロジェクトからインポートできるツールです。
Unity

BoothFolderIcons →

プロジェクトのフォルダに画像アイコンを設定し、アセットを検索するツールです。
Unity

フェイスメニュービルダー →

アバターの表情から、Expression Menuと各表情のアイコンを自動生成するツールです。
Unity

アイコンスタジオ →

Expression Menu用アイコンや紹介画像を撮影し、FFmpeg連携で動画も出力するツールです。
